# RK-033 应变模块采集（ESP32-S3 / ESP-IDF v6.1）

读取 RK-033 V2.0 的 OUT 模拟电压，输入为用户指定的 **GPIO4 / ADC1 通道 3**。模块使用模拟输出，不需要 HX711 或 I2C 驱动。

本项目仅测量一个方向的弯曲，不设置零点推荐上下限。终端在读数变化时输出读数和变化量，相同读数不重复输出，不判别或显示弯曲方向；量程和错误提示只在状态改变时输出。变化量仍为当前读数减去零点，保留电气变化的正负号。

## 接线条件

照片确认了 GND / VCC / OUT 和“支持单桥 350Ω”，**没有确认 VCC 允许范围、OUT 最大电压、放大倍数和电位器功能**。VCC 按该版本厂家说明书供电，不能凭外观决定接 3.3V 或 5V；应变片标称阻值也应查规格或断电测量确认。

先断开 OUT 与 ESP32 的连接，确认供电规格，再用万用表检查 OUT 对 GND 的电压及预期变化范围。下方可选分压方案用于已确认 **OUT 为非负、最大不超过 5V** 的情况；若超出，先重新设计前端再接入。

## 当前接线与电压比例

用户已确认模块 VCC 接 3.3V，OUT 直接接 GPIO4，且不弯曲应变片时 `raw=4095`。代码已按此直连接线设置 `STRAIN_OUTPUT_TO_ADC_RATIO = 1.0f`。供电值是用户报告的接线情况，不代表已经核实模块支持 3.3V 供电。

```text
RK-033 OUT ── ESP32-S3 GPIO4 (ADC1_CH3)
RK-033 GND ── ESP32 GND
```

直连时 GPIO4 电压就是 OUT 电压。确认 OUT 整个工作范围符合 GPIO 和 ADC 输入要求后再连接；即使模块用 3.3V 供电，高端输出仍可能超过 ADC 有效量程。静止时已经满量程的输入不能通过软件归零恢复，需先测量电压、检查模块供电与桥路平衡。

## 可选分压方案：OUT 经二分之一分压接 GPIO4

**若改成以下接线，必须把 `main/main.c` 中的 `STRAIN_OUTPUT_TO_ADC_RATIO` 改为 `2.0f`。当前默认仍是直连的 `1.0f`。**

| 模块/元件 | 连接 |
| --- | --- |
| 模块 GND | ESP32 GND |
| 模块 VCC | 厂家规定的电源；外部电源与 ESP32 共地 |
| 模块 OUT | 10kΩ 电阻 Rtop 的一端 |
| Rtop 另一端 | GPIO4，同时接 Rbottom 和电容的上端 |
| 10kΩ 电阻 Rbottom 另一端 | GND |
| 100nF 电容另一端 | GND；电容靠近 GPIO4 放置 |

```text
RK-033 OUT ── Rtop 10kΩ ──┬── ESP32-S3 GPIO4 (ADC1_CH3)
                         │
                         ├── Rbottom 10kΩ ── GND
                         │
                         └── 100nF ───────── GND

RK-033 GND ───────────────── ESP32 GND
RK-033 VCC ───────────────── 模块规定的电源
```

理想分压：`Vadc = Vout × Rbottom / (Rtop + Rbottom)`。两个电阻相等时，5V OUT 变成约 2.5V ADC 输入，3.3V OUT 变成约 1.65V；这是计算值，不是模块实测数据。

分压模式的 `STRAIN_OUTPUT_TO_ADC_RATIO = 2.0f` 用来还原分压前的模块电压。如果分压值不同，应修改为 `(Rtop + Rbottom) / Rbottom`。精度要求较高时使用实测阻值并与万用表核对；电阻误差、模块输出驱动能力和 ADC 误差都会影响结果。修改比例只影响显示，不改变实际输入电压或 ADC 量程。

GPIO 不可直接接 5V，12dB 衰减也不代表 GPIO 耐受 5V。此分压不是过压保护器；若模块可能输出高于 5V、负电压或尖峰，需要匹配的保护电路。连接前确认开发板的 GPIO4 未接其他外设。

## 程序行为

1. 用 `adc_oneshot_io_to_channel()` 由 GPIO4 查询 ADC1 通道 3，配置 12 位、`ADC_ATTEN_DB_12`。
2. 每组连续采样 32 次并取平均，保留本组最小值和最大值。
3. 按本组单次采样极值检查是否触及 0 或 4095；即使平均值尚未达到端点，只要其中一次采样触及端点，本组就标记量程状态。显示任务汇总整个显示窗口的极值，在端点状态改变时提示，继续提供可用读数。
4. 用 ESP32-S3 curve-fitting ADC 校准 API 转成 mV，包括端点读数。端点时显示的电压仅为 ADC 换算值，不能判断真实输入超过量程的程度。缺少芯片校准数据时仍提供原始计数和计数变化，电压显示不可用。
5. 启动等待 3 秒，再用 32 组读数归零，组间等待 20ms。归零期间保持已安装的应变片处于希望作为零点的机械状态。全部读取成功后保存参考值；采样触及 0 或 4095 时仅提示，仍允许归零，不设置其他零点范围或余量提示。端点参考值的后续变化仅供观察。
6. 归零完成后，目标每 **10ms 采集一组（100 组/秒）**，每组仍连续采样 32 次并平均，对应目标平均约 **3200 次 ADC 转换/秒**。读取失败时丢弃本组。采集使用 `xTaskDelayUntil()` 按调度节拍运行，并非硬件等间隔连续采样；若未能按期进入等待，会记录并在显示任务中提示，实际频率需运行测量。
7. 独立显示任务每 **50ms 接收一个显示窗口**，首次有效读数输出一次；此后仅在窗口内最后一组有效读数相对上次输出发生变化时输出，相同读数保持静默。变化判断精确比较平均原始值、有效电压和已归零的变化量，不设变化阈值；组内最小值和最大值的波动本身不触发重复输出。持续变化时，读数日志目标上限为 **20 次/秒**；显示的是最后一组读数，不把整个窗口再次平均。
8. 整个显示窗口的单次采样极值用于端点状态提示，状态持续相同时不重复警告，恢复未触及端点时提示一次；读数后的方括号仍表示最后一组的极值。读取错误和采集超时也只在状态改变时提示，持续相同故障不重复刷屏。启动信息和归零结果仍输出一次。
9. 采集任务通过单元素队列向显示任务传递数据副本，不等待串口打印。串口拥堵时旧显示窗口会被最新窗口覆盖，因此终端日志不是全部采样数据的存档；被覆盖窗口的读数和端点提示也可能不再显示。需要完整波形时应另加数据缓冲及足够带宽的数据传输或存储。

### 采样速度与精度

旧版 200ms 是每组读数及串口输出的间隔，并非 ADC 完成一次转换的时间或硬件速度上限。本次将采样组的目标频率从 5 组/秒提高到 100 组/秒，为原来的 20 倍；日志改为变化时输出，使用 50ms 显示窗口限频。可在 `main/main.c` 中通过 `STRAIN_SAMPLE_INTERVAL_MS` 和 `STRAIN_REPORT_INTERVAL_MS` 分别调整。

由于没有变化阈值，即使试件静止，ADC 噪声引起平均原始值相差 1 个计数，也会被视为变化。相邻显示窗口之间先变化又回到原值的过程可能不出现在日志里；日志变化频率不等于真实采样频率。

当前 `CONFIG_FREERTOS_HZ=100`，一个调度节拍为 10ms；不能只把采集间隔改为 1ms，否则 `pdMS_TO_TICKS()` 会得到 0，源码中的静态断言会阻止这种配置。任务调度、32 次读取的耗时及其他系统负载仍可能影响实际频率。

更高采样率可采用 ADC continuous + DMA，但本次仍使用 oneshot 驱动。当前 ADC 为 12 位，原始计数范围仍为 0～4095；提高频率不等于提高电压精度，也不能恢复已经饱和的信号。RK-033 模块带宽尚未核实，不能把软件采样频率直接当成整套传感器系统的有效带宽。

归零成功不能保证参考值未限幅、模块放大器未饱和，也不能保证整个弯曲行程都不会超量程。参考值或当前采样触及端点时，电压和相对变化仅供观察；软件继续显示数值不能恢复被截断的信号。

串口格式示例（仅示意，未测得硬件数据）：

```text
I (...) 应变传感器: GPIO4 对应 ADC1 通道 3，分辨率 12 位，衰减 12 dB，每组平均 32 次
I (...) 应变采集: 原始值=... [...]，引脚电压=... mV，模块输出=... mV，输出变化=... mV，计数变化=...
W (...) 应变采集: 最近显示窗口原始范围=[4095..4095]，状态=触及 ADC 端点 4095；继续显示 ADC 换算值，电压及相对变化仅供观察，请检查实际 OUT 电压
I (...) 应变采集: 原始值=4095 [4095..4095]，引脚电压=... mV，模块输出=... mV，输出变化=... mV，计数变化=...
```

| 字段 | 含义 |
| --- | --- |
| 原始值 | 本组 ADC 平均原始值，取整，范围 0～4095 |
| 原始值后的方括号 | 本组最小值和最大值，可观察波动及端点触及情况 |
| 引脚电压 | GPIO4 原始计数经 ADC 校准函数换算的电压 |
| 模块输出 | 按实际接线比例还原的模块输出电压 |
| 输出变化 | 当前模块输出减去零点输出，保留电气变化的正负号 |
| 计数变化 | 当前原始计数减去零点计数，保留正负号 |

上电归零失败时继续输出绝对读数或量程状态，变化量显示不可用。修正硬件后保持试件在参考状态，并复位重新归零；组件也提供 `strain_sensor_zero()`，可供后续按键调用。重新归零失败会保留已有零点。程序不会在弯曲过程中自动追踪或移动零点，以免把持续形变消除。零点只保存在 RAM，每次复位重新采集。模块温漂和胶层蠕变需按实际实验确定稳定时间，3 秒仅为初始演示参数。

工程自编写的源代码注释及应用日志已改为中文，源文件使用 UTF-8。使用第三方串口工具时应选择 UTF-8 接收编码。ESP-IDF、启动加载程序和构建工具自带的日志，以及错误代码、单位和接口名称，保留其原有格式。

软件不提供过压保护，也不能单凭 ADC 端点判断模块放大器是否饱和或应变片是否断线。OUT 不随形变变化时仍需测量实际输出，检查贴装、桥路和供电。

## 单向弯曲测量的硬件调整

1. 先断开 OUT 与 GPIO4，用万用表测量实际 VCC，以及参考状态、目标弯曲行程内的 OUT。
2. 若 OUT 随目标弯曲变化，而 ADC 读数停在端点，应匹配 ADC 输入量程；若模块 OUT 本身已经停在供电端附近，应先检查模块供电、桥路平衡和放大器工作范围。
3. 在厂家说明确认电位器功能后，调整模拟零点和必要的增益，使参考状态处于可测范围内，并为目标弯曲时计数减小留出足够余量，不再要求零点位于量程中部。
4. 调整后复位，在参考状态保持静止，等到中文日志提示“归零完成”。然后在预定弯曲行程内观察“输出变化”和“计数变化”，并确保整个所需行程不触及端点。

仅修改显示比例、软件归零或增加输出分压，都无法恢复模块放大器已经饱和的信号。不要以增大弯曲程度或对折应变片代替硬件调零。

## 静止就满量程时的排查

1. 暂时断开模块 OUT 与 GPIO4，在 ESP32 上将 GPIO4 经 1kΩ 接 GND。应读到接近 0；若采样触及 0，程序会提示触及 ADC 端点 0，并继续显示可用的换算数值。此步不能证明 ADC 整个量程正常，但可检查引脚、接地及基本采集。
2. 可用两个 10kΩ 电阻在 ESP32 的 3V3 与 GND 间分压，把中点接 GPIO4；理论电压为实测 3V3 的一半（标称约 1.65V）。若读数稳定且与万用表接近，可继续检查模块。
3. 用万用表测量模块 GND 参考下的 VCC 和静止 OUT。满量程日志里的 `ADC=3134mV` 只是校准函数对 4095 的映射，不证明实际 OUT 恰为此值；原 `OUT=6268mV` 还包含不符合直连接线的两倍系数。
4. 若静止 OUT 已接近供电高端，查该版本供电规格、应变片实际阻值及焊点、桥路平衡。蓝色电位器功能尚未核实，只有说明书确认其为零点/平衡调节时才据此调节；不要把修改显示系数或软件归零当作模拟前端调零。
5. ADC 分压能让较高的 OUT 落入 ADC 量程，但无法恢复模块放大器本身已经饱和的信号。应使静止输出处于可测范围并为预期形变留有余量，再复位归零。

如果应变片尚未粘贴在试件上而是悬空弯折，这只能用于观察定性变化，无法代表试件应变。不要折出永久折痕或拉扯焊点及细导线；正式测量应粘贴在被测弹性体表面，并做引线应力释放。

## 测量边界和核对依据

没有已核实的应变片灵敏系数、桥路激励、桥型、模块增益和机械标定，**不能把 mV 直接换算为 με、N、g 或 mm**。ADC 电压校准不等于整套应变系统标定；平均只能降低部分随机噪声，不能保证绝对精度。

本地 ESP-IDF v6.1 源码核对依据：

- `components/soc/esp32s3/include/soc/adc_channel.h`：`ADC1_GPIO4_CHANNEL = 3`。
- `components/esp_adc/include/esp_adc/adc_oneshot.h`：GPIO 查询、oneshot 采样和校准电压建议。
- `components/esp_adc/include/esp_adc/adc_cali_scheme.h`：curve-fitting 校准配置及 eFuse 缺失错误处理。
